# Sponsor target list

Drafted 2026-07-26, resolving part of [#52](https://github.com/codeswithroh/tastemaker/issues/52). **Not sent** — outreach is a manual step for the repo owner.

## What "companies say yes to this category" is based on

Verified directly against [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (67.7k stars) — the actual anti-slop skill this project has studied throughout for structural/architectural comparison. Its real sponsor list: **Novamira** (WordPress AI-agent access), **IMG.LY** (creative-editor SDK), **Sent.dm** (messaging APIs), **Vercel** (Open Source Program), and individually, **Emil Kowalski** (animations.dev). That's the evidence base for "who actually says yes" below — not a guessed list of big-name dev-tool companies.

## An honest framing before the list

taste-skill had 67.7k stars when it landed those sponsors; tastemaker has 58, three weeks old. This list is realistic outreach targets for an early-stage project on the strength of technical depth and category fit, not an expectation of taste-skill's response rate. Expect most of these to be a "not yet, check back after more traction" — that's normal, not a sign the pitch is wrong.

## Sequencing recommendation

Approach #1-4 first — they have a proven, verified track record of saying yes to this exact category, so the response rate should be meaningfully higher than the rest. Don't wait for all four responses before approaching #5-10; run them in parallel, but weight follow-up effort toward the first group.
